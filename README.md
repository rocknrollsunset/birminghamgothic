# birminghamgothic.com

Static site for Birmingham Gothic, Ray Carroll's fiction imprint (part of rocknrollsunset).
Served by GitHub Pages from the `main` branch root. bhamgothic.com forwards here from Porkbun.

- `index.html`, `404.html`: the pages
- `assets/site.css`: all styles
- `assets/*.jpg|webp`: hero layers (sky, record, shine, cedars) drawn with the book cover's generator
- `CNAME`: the custom domain for GitHub Pages

To change the page, edit `index.html` and push to `main`. GitHub Pages republishes in about a minute.
